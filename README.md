# MIDAD AI LAB

مختبر مِداد للذكاء الاصطناعي متعدد الوسائط.

## الحالة الحالية
هذه هي النسخة التأسيسية: واجهة عربية متجاوبة، ومخطط API أولي. لا تدّعي الواجهة توليد محتوى حقيقياً قبل إعداد وتشغيل مزود نموذج مناسب.

## الوحدات المستهدفة
- النصوص
- الصور
- الصوت
- الفيديو

## البنية
- `index.html`, `styles.css`, `app.js`: واجهة الويب.
- `worker/index.js`: نقطة خلفية أولية لـ Cloudflare Workers.
- `wrangler.toml`: إعداد نشر العامل.

## التشغيل
افتح `index.html` محلياً أو انشر المستودع عبر Cloudflare Pages.
للتوليد الفعلي، انشر العامل وفق `wrangler.toml` وأضف مزود نموذج مدعوماً بعد اختيار النموذج ومراجعة الترخيص والتكلفة.

## الأمان
لا تضع مفاتيح API في ملفات الواجهة أو المستودع. استخدم أسرار Cloudflare Worker.
